# 课酬助手移动端 → 管理后台接口迁移计划

## 一、需求概述

将移动端项目 `teach-salary-app` 的核心功能模块添加到管理后台 `teach-salary-admin` 中，使管理后台具备完整的管理能力。

## 二、现有模块分析

### 移动端 (teach-salary-app) 模块结构
| 模块 | 功能描述 | 页面文件 |
|------|----------|----------|
| 学生管理 | 学生信息的增删改查 | pages/student/index.vue, sub_pages/student/ |
| 分组管理 | 学生分组管理 | sub_pages/bus_group/ |
| 课程管理 | 课程增删改查、排课 | sub_pages/course/ |
| 排课管理 | 排课列表、添加、修改 | sub_pages/schedule/ |
| 课节管理 | 课节列表、批量添加、消课 | sub_pages/section/ |
| 结算管理 | 结算列表、详情、导出 | sub_pages/checkout/ |
| 首页 | 数据概览、统计 | pages/index/index.vue |
| 课表 | 日历视图展示 | pages/course/timeTable.vue |

### 管理后台 (teach-salary-admin) 现有模块
| 模块 | 状态 |
|------|------|
| 课程管理 | ✅ 已实现 (views/course/) |
| 分组管理 | ✅ 已实现 (views/group/) |
| 学生管理 | ⚠️ 有API，无完整页面 |

## 三、需要添加的模块

### 1. 学生管理 (views/student/)
- 页面：`index.vue` (列表页)
- 表单：`form/index.vue` (新增/编辑弹窗)
- 工具函数：`utils/hook.tsx`, `utils/types.ts`, `utils/rule.ts`
- 路由：`router/modules/student.txt`

### 2. 排课管理 (views/schedule/)
- 页面：`index.vue` (列表页)
- 表单：`form/index.vue` (新增/编辑弹窗)
- 工具函数：`utils/hook.tsx`, `utils/types.ts`, `utils/rule.ts`
- 路由：`router/modules/schedule.txt`
- 功能：日历视图、排课列表

### 3. 课节管理 (views/section/)
- 页面：`index.vue` (列表页)
- 表单：`form/index.vue` (新增/编辑弹窗)
- 工具函数：`utils/hook.tsx`, `utils/types.ts`, `utils/rule.ts`
- 路由：`router/modules/section.txt`
- 功能：批量添加、消课处理

### 4. 结算管理 (views/checkout/)
- 页面：`index.vue` (列表页)
- 详情页：`detail.vue` (结算详情)
- 工具函数：`utils/hook.tsx`, `utils/types.ts`
- 路由：`router/modules/checkout.txt`
- 功能：执行结算、导出Excel
